# MERIX NEXT — MERIX STUDIO

Premium mobile-first studio portfolio built with Next.js 15, React 19 and TypeScript.

## Run

```bash
npm install
npm run dev
```

## Deploy

Import this GitHub repository into Vercel and select the Next.js framework preset.

## Notes

Project thumbnails are intentionally stylized placeholders until approved real project screenshots are provided. The brand wordmark is CSS typography until the official logo asset is added. The contact CTA uses email; no backend form is connected yet.
